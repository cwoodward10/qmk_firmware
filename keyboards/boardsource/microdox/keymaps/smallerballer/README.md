# The Smallerballer Keymap

The goal of this keyboard is to get the keys that I use in frontend dev front and center on the sym and num layers. The other layers are mostly fluff but hopefully will be useful.

## Build & flashing this keymap

- Open `QMK MSYS` and use the command `qmk compile -kb boardsource/microdox/v2 -km smallerballer`
- Open `QMK Toolbox`
- Use a cable to reset the keyboards (touch the `gnd` and `rst` points on the controllers)
- Flash each half with the new firmware
